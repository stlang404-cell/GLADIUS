# GLADIUS — The Eternal Chess Empire

An offline-first Roman chess career game. Real FIDE chess, fully 2D and untimed, against a living empire of 25,000 persistent AI competitors across 24 arenas, 72 ranks and eight regional circuits — with Elo, tournaments, championships, rivalries, a Hall of Fame, live spectating and full Stockfish analysis.

- **Play:** `npm install && npm run dev`, or see [docs/DEPLOY.md](docs/DEPLOY.md) for the Windows one-click package and iPhone PWA.
- **Design & architecture:** [docs/DESIGN.md](docs/DESIGN.md)
- **Status, tests and known limitations:** [docs/STATUS.md](docs/STATUS.md)
- **Analysis model:** [docs/ANALYSIS.md](docs/ANALYSIS.md) · **Engine & benchmarks:** [docs/ENGINE.md](docs/ENGINE.md) · **World rules & API:** [docs/WORLD.md](docs/WORLD.md), [docs/WORLD_API.md](docs/WORLD_API.md)

Five tabs: **Arena · Empire · Academy · Spectate · Legacy**.
