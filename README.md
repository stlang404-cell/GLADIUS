# GLADIUS — The Eternal Chess Empire

An offline-first Roman chess career game. Real FIDE chess against a living empire of 5,000 persistent AI competitors, with Elo, 12 arenas, 36 ranks, tournaments, championships, live spectating and full Stockfish analysis.

- **Play:** `npm install && npm run dev`, or see [docs/DEPLOY.md](docs/DEPLOY.md) for the Windows one-click package and iPhone PWA.
- **Design & architecture:** [docs/DESIGN.md](docs/DESIGN.md)
- **Status, tests and known limitations:** [docs/STATUS.md](docs/STATUS.md)

Five tabs: **Arena · Empire · Academy · Spectate · Legacy**.
